PROJECT OVERVIEW

IoT 수집 및 모니터링

센서 데이터 수집부터 조회와 부하 검증까지

게이트웨이가 보내는 센서 데이터를 TCP로 수집하고, 모니터링 API에서 측정 이력을 조회하는 백엔드입니다.
냉매와 콜드체인의 공통 수집 구조를 재사용하고 서비스별 조회 / 알림 요구를 확장하도록 경계를 잡았습니다.

JavaSpring BootJava NIOMySQLAWS

역할과 기여

TCP 수집 서버와 모니터링 API를 개발하고, 조회 성능 개선과 가상 게이트웨이 부하 시험을 수행했습니다.

수집 서버

Java NIO 프레임 수신 / 파싱
Outbox 기록 / 커밋 후 ACK

모니터링 API

센서 측정 이력 조회
실행 계획 / 인덱스 점검

부하 검증

시험 시나리오 / 지표 설계
회차별 결과 시각화 / 기록

서비스 구성

게이트웨이센서 데이터 TCP 전송
→
수집 서버프레임 조립 → Outbox 저장 → ACK
→
전달 / 조회HTTP 이벤트 전달 → 모니터링 API

주요 성과

  • 조회 병목 개선실제 DB에 누락된 복합 인덱스를 적용해 센서 테이블의 전체 스캔을 인덱스 조회로 변경했습니다.
  • 목표 규모 검증500대 동시 접속을 5회 시험해 2,500건 모두 시험 기준인 10초 이내 ACK를 확인했습니다.
  • 한계 확인1,000대 시험에서 응답 기준을 넘긴 요청을 확인하고 공유 DB 자원과 커넥션 대기 영향을 검토했습니다.
