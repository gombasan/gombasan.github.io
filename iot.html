PROJECT OVERVIEW

IoT 수집 및 모니터링

센서 데이터 수집부터 조회와 부하 검증까지

게이트웨이가 보내는 센서 데이터를 TCP로 수집하고, 모니터링 API에서 측정 이력을 조회하는 백엔드입니다.
냉매와 콜드체인에서 공통으로 쓰는 수집 기능은 재사용하고, 조회와 알림 기능은 서비스에 맞게 개발할 수 있도록 나눴습니다.

JavaSpring BootJava NIOMySQLAWS

역할과 기여

TCP 수집 서버와 모니터링 API를 개발했습니다.
조회 성능을 개선하고 가상 게이트웨이로 부하 테스트도 진행했습니다.

수집 서버

Java NIO로 프레임 수신과 파싱
Outbox 저장과 커밋 후 ACK 전송

모니터링 API

센서 측정 이력 조회
실행 계획과 인덱스 확인

부하 검증

테스트 시나리오와 측정 항목 설계
회차별 결과를 그래프와 JSON으로 기록

서비스 구성

게이트웨이센서 데이터 TCP 전송
→
수집 서버프레임 조립 → Outbox 저장 → ACK
→
데이터 전달과 조회HTTP 이벤트 전달 → 모니터링 API

주요 성과

  • 조회 병목 개선DB에 빠져 있던 복합 인덱스를 추가해 센서 테이블 전체를 읽던 쿼리가 인덱스를 사용하도록 개선했습니다.
  • 500대 동시 접속 테스트500대 동시 접속 테스트를 5회 진행했고, 2,500건 모두 기준으로 정한 10초 안에 ACK를 받았습니다.
  • 1,000대에서 응답 지연 확인1,000대 테스트에서는 10초 안에 ACK를 받지 못한 요청이 있어, 공유 DB의 부하와 커넥션 대기 시간을 살펴봤습니다.
