01. 운영자가 직접 조사할 수 있는 API

운영자가 문의를 받으면 HBL 번호로 고객 화물의 상세 데이터를 조회할 수 있도록 관리자 API를 개발했습니다. 회원 이용 상태 관리, 활동 로그 조회, 공지 등록도 관리자 API로 제공했습니다.

02. 공개 범위와 API 계약을 먼저 정하기

초기 Figma 기획 협의에서 화물 관리와 공유 정책을 함께 정했습니다.
같은 선적을 보는 고객이라도 각 HBL의 첨부 문서는 수출자, 수입자, 파트너 포워더별로 공개 범위가 달라야 했습니다.

공통 운송 정보는 MBL에서 관리하고, 고객 화물별 컨테이너 연결과 첨부 문서는 HBL에서 관리했습니다.
문서별 접근권한을 확인한 뒤 S3 Presigned URL을 제공했습니다.

프론트엔드와 구현을 병행한 방식

구현 전에 API 계약과 응답 예시를 공유했습니다.
처음에는 테스트를 통과한 API 내용을 문서에 반영하기 위해 Spring REST Docs를 사용했습니다.
이후 프론트엔드 개발자가 문서에서 API를 직접 호출해 보고 싶다고 해 Swagger UI로 전환했습니다.

GitHub Actions에서 JAR 빌드와 EC2 배포를 자동화했습니다.
