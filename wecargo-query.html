01. HBL 한 건이 목록의 한 행

목록 화면의 한 행은 고객 화물인 HBL 한 건입니다.
검색 조건과 정렬, 접근권한을 적용한 HBL 목록을 DB에서 페이징하면서 각 화물에 연결된 컨테이너를 함께 보여줘야 했습니다.

목표는 HBL 단위 페이징을 유지하면서 반복 조회를 줄이는 것이었습니다.

02. 반복 호출을 일괄 조회로

직접 ID 참조 구조 / DTO 페이징 유지

기존에는 Page<HBLInfo>를 조회한 뒤 응답을 조립하는 과정에서 HBL마다 findByHblId(hblId)를 호출했습니다.
페이지가 10건이면 이 컨테이너 조회도 10번 실행되는 구조였습니다.

Batch Size만으로 바뀌지 않았던 이유

먼저 Batch Size를 적용했지만 컨테이너 조회가 IN 쿼리로 바뀌지 않았습니다.
당시 Container.hblId는 단순 ID였고, DTO 응답 조립 중 저장소 메서드를 직접 호출했습니다.
이 경로는 Hibernate가 지연 로딩 컬렉션을 묶는 배치 페칭 대상이 아니었습니다.

기존HBL DTO 페이지 조회
→
응답 조립각 HBL마다 컨테이너 조회
→
HBL 10건컨테이너 조회 10회
변경같은 DTO 페이지 조회
→
일괄 조회페이지의 HBL ID로 IN 조회
→
응답 조립HBL ID별로 묶어 응답에 연결

findByHblIdIn(hblIds)로 필요한 컨테이너를 한 번에 가져오도록 바꿨습니다.
HBL 페이징과 검색 조건은 유지하고, 응답을 만들 때 HBL마다 컨테이너를 조회하던 부분을 바꿨습니다.

10회 → 1회

HBL 10건에서 컨테이너 조회 메서드 호출을 10회에서 1회로 줄였습니다.
코드 기준으로 계산한 값입니다.

03. 페이지와 연관 데이터 조회 분리

HBL ID를 먼저 페이징한 뒤 연결 데이터 조회

HBL과 컨테이너의 연결 정보는 HBLContainer에 저장합니다.
일대다 컬렉션을 페이지 쿼리에 바로 fetch join하면 하나의 HBL이 여러 결과 행에 중복으로 나타나 HBL 단위로 DB 페이징을 하기 어려워집니다.

현재 모델의 관계

MBL → HBL공통 선적 정보와 고객별 화물
HBL에서 MBL ID 참조
MBL → Container선적의 실제 컨테이너 정보
MBL을 조회할 때 함께 가져옴
HBL → HBLContainer화물별 컨테이너 연결 컬렉션
이 구간을 fetch join
HBLContainer ⇢ ContainercontainerId로 참조
응답을 만들 때 ID로 연결
1. HBL ID 페이징검색 조건, 권한, 정렬을 적용해 HBL ID 조회
→
2. 연결 조회확정된 ID의 HBL과 HBLContainer fetch join
→
3. 컨테이너 정보 연결MBL 경로의 Container를 ID로 연결

전체 건수는 별도로 조회합니다.
fetch join 범위는 HBL → HBLContainer까지이며, 실제 Container 엔티티까지 한 번에 fetch join하는 구조는 아닙니다.

조회 방법 비교

방법판단
페이지 쿼리의 컬렉션 fetch join행이 늘어나 HBL 단위 DB 페이징에 부적합
Batch Size직접 저장소 호출을 묶지 못함. 연관관계 로딩에서는 가능한 대안
ID 선페이징 + 연관 데이터 조회페이지를 먼저 확정한 뒤 필요한 컬렉션만 로딩

페이지를 확정한 뒤 연결 데이터를 조회하는 코드

첫 쿼리는 페이지에 들어갈 HBL ID만 가져옵니다. 두 번째 쿼리는 그 ID로 연결 정보를 조회해 응답을 조립합니다.

// Querydsl 의사 코드
List<Long> ids = query.select(hbl.id).from(hbl)
    .where(searchConditions, accessScope)
    .orderBy(listOrder)
    .offset(page.offset()).limit(page.size())
    .fetch();

List<Hbl> rows = query.selectFrom(hbl)
    .leftJoin(hbl.links, link).fetchJoin()
    .where(hbl.id.in(ids))
    .orderBy(listOrder) // IN 조건 자체는 순서를 보장하지 않음
    .fetch();

long total = countWithSameFilters();
var containers = loadContainersThroughMbl(rows);
return assemble(rows, containers, total);
