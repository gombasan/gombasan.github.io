PROJECT OVERVIEW

WECARGO

포워더와 고객을 연결하는 B2B 물류 플랫폼

포워더가 선적과 고객 화물을 관리하고, 운송 일정과 문서를 고객 및 파트너와 공유하는 서비스입니다.
여러 고객이 같은 운송 일정을 확인하면서 각자의 화물과 문서는 따로 관리할 수 있도록 설계했습니다.

JavaSpring BootJPAQuerydslMySQLAWS

초기 기획부터 도메인 설계, 서비스 및 관리자 API 개발, AWS 배포와 운영까지 백엔드를 담당했습니다.

주요 성과

  • HBL 페이징 유지HBL마다 반복하던 컨테이너 조회를 한 번에 가져오도록 바꿨습니다. 연관관계를 사용하는 구조에서는 HBL ID를 먼저 페이징하고 연결 데이터를 조회했습니다.
  • 고객별 문서 공개같은 선적을 공유하더라도 화물별 문서 접근 범위를 구분했습니다.
  • 운영 업무 지원운영자가 HBL 번호로 화물을 조회해 오류를 확인할 수 있는 관리자 API를 개발했습니다. 배포를 자동화하고 주요 이벤트는 Teams로 알리도록 했습니다.
